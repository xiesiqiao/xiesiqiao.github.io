# xiesiqiao.github.io

Personal academic site of Siqiao Xie. Plain HTML, CSS, and one small script; no framework, theme, or build step.

- `index.html` (home), `research/`, `papers/`, `data/`, `cv/` — one plain HTML page each; the header and footer are repeated in each file, so edit all five if you change them
- `assets/style.css` — styles
- `assets/grid.js` — draws the illustrative population grid in the header
- `files/papers/` — first-author PDFs linked from the Papers page
- `assets/fonts/` — self-hosted fonts (no Google Fonts, so the site loads where Google is blocked)
- `files/Xie_CV.pdf` — CV
- Folders like `publications/`, `portfolio/`, `about/` only redirect old links to the new page.

To update: edit `index.html`, replace PDFs in `papers/` or `files/`, commit, push. GitHub Pages publishes within a minute.
